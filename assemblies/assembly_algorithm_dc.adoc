== A Computer Algorithm for Reduction and Presentation of Information from the BNW DC-3 Data Acquisition System
[.big]#{DRD}#

_The data acquisition system aboard the BNW DC-3 research aircraft records data, as voltage signals, in a compact format on {7track}. Computer software has been written which converts these data to inappropriate units and makes them available for analysis, and the modular nature of the code allows great flexibility in the types of analysis to be performed. In addition to printed output, graphic output may be generated using the highly versatile DISSPLA graphics package._
