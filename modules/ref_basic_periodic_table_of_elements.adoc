The Periodic Table of elements contains eight categories of element type: 

* Reactive Non-Metals

* Noble Gases

* Metalloids

* Post-Transition Metals

* Alkaline Earth Metals

* Transition Metals

* Lanthanide

* Actinides

* Unknown Chemical Properties
