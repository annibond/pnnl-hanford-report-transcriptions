A diagram showing the difference between *cations* and *anions*. The direction in which the ion is charging is the *opposite* of the type of subatomic particle it is losing.

* An *anion* is a *negatively charged ion*. Losing positrons result in becoming an anion.

* A *cation* is a *positively charged ion*. Losing electrons results in becoming a cation.
