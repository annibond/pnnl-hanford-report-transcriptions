NOTE: A number raised up (superscript) on the *left* side of an isotope denotes the mass number (the number of protons and neutrons). For example, Beryllium with a mass number of 7 is written as ^7^Be. If there is no superscript, the isotope is stable and the number of protons and electrons are equal.
